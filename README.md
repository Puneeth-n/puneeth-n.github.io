# Personal Website

A simple, clean personal website showcasing my professional profile and social links.

## Structure

- `index.html` - Main website page
- `assets/` - Directory for any images or other assets
- `robots.txt` - Search engine crawling instructions

## Features

- Clean, modern design
- Responsive layout
- Social media links
- Mobile-friendly

## Technologies Used

- HTML5
- CSS3
- No external dependencies

## Local Development

Simply open `index.html` in your web browser to view the website locally.

## Deployment

This website is deployed using GitHub Pages and is available at [puneeth-n.github.io](https://puneeth-n.github.io).
